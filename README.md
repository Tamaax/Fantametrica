# ⚽ Fantametrica
> Un'applicazione web per la gestione di listoni e aste del Fantacalcio.

## 📋 Descrizione
Fantametrica è un progetto che ti permette di gestire le quote dei giocatori, visualizzare statistiche, creare vere e proprie aste, ecc.

## ✨ Funzionalità
- **📊 Tool Statistiche**: Analisi approfondita dei giocatori con filtri per ruolo, squadra e periodo di forma. Confronti diretti e monitoraggio dei trend.
- **📋 Tool Listone**: Gestione completa della rosa con valutazione crediti, simulazione formazioni e consigli personalizzati per ottimizzare la squadra.
- **🏆 Tool Aste**: Simulazioni, pianificazione acquisti e analisi del valore di mercato per arrivare preparato all'asta.
