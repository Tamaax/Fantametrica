# Come contribuire a Fantacalcio

Grazie per il tuo interesse nel contribuire! Segui queste linee guida:

## 🐛 Segnalare un bug
1. Vai alla sezione [Issues](https://github.com/Tamaax/Fantametrica/issues)
2. Clicca su "New Issue"
3. Scegli il template "Bug Report"
4. Compila con il massimo dettaglio

## 💡 Proporre una nuova funzionalità
1. Vai alla sezione [Issues](https://github.com/Tamaax/Fantametrica/issues)
2. Clicca su "New Issue"
3. Scegli il template "Feature Request"

## 🔧 Come inviare una Pull Request
1. Fai un fork del repository
2. Crea un nuovo branch (`git checkout -b feature/nuova-funzione`)
3. Fai le tue modifiche
4. Fai commit delle modifiche (`git commit -m 'Aggiunta nuova funzione'`)
5. Fai push sul branch (`git push origin feature/nuova-funzione`)
6. Apri una Pull Request

## 📝 Stile del codice
- Usa nomi di variabili descrittivi in inglese
- Commenta il codice quando necessario
- Segui le best practice del linguaggio
